## 第八节 世应的作用



世爻是卦的中心点，是卦的灵魂所在。预测自己的运气、身体、我方情况，一般是以世爻来展开判断的。世爻也是预测事物的一个焦点，通常不宜克用神的六亲持世，也不宜旬空、月破（旬空、月破详见后述）应爻是与世爻相对应的人或场所、事件等，也为与自己关系不密切的人或是与自己对立的人以及共同发展事业的伙伴、恋爱对方、旅行目的地等。



所有的预测都需要看世爻对用神的作用如何，它反映了求测者本人对所测事物的立场和心态，也表示事物发展的阶段信息。为了使大家很好地把握预测的要点，现把各个六亲持世常常代表的含义介绍如下。



子孙持世：预测买卖、出行、烦恼、出差、事物为吉，预测升学、考试、官职、女子婚姻、丈夫疾病等则不吉。以之为吉，则是无忧无虑、少病少灾，高高兴兴、快乐之象，以之为不吉，则是郁闷、无精打采、情绪低落之象。



兄弟持世：预测买房、获奖、文书、信件等之事为吉，预测买卖、财运、男子婚姻、灾难等则不吉。以之为吉，则是讲义气、朋友众多之象，以之为不吉，则是破财、花钱、没有女人缘之象。



父母持世：预测升学考试、信件、文书、契约等为吉，预测孩子疾病、生育为不吉。以之为吉，则是捷报频传、获奖、财来追我之象，以之为不吉，则是辛苦、劳碌、心情郁闷等之象。



妻财持世：预测买卖、男子婚姻、财运、失物等为吉，预测父母、长辈、买房、买地等则不吉。妻财持世，以之为吉则是财运亨通、失物可觅之象，以之为不吉，则是契约不成，与父母缘分薄之象。



官鬼持世：预测官位、升迁、调工作、女子婚姻、考试升学等为吉，预测疾病、兄弟安危等则不吉。官鬼持世以之为吉，乃是得官、得名、前程似锦之象，以之为不吉，则是疾病缠身、苦恼非常、灾难临身之象。



以上只是从六亲持世的角度简单进行对事物的判断，高层次的预测，则要看日月对世爻的影响，以及卦中其它爻对用神的动静生克，然后再结合爻位、六神等，才能做出细致准确的判断。



# 第九章 取用神的方法



六爻预测最重要的、最先进行的是取用神。**用神是展开六爻预测的核心，一切事情的吉凶与发展都围绕着用神来分析推理，用神取错，失之毫厘，差之千里。**因此，在预测时，必须问明求测者的目的或来测者与被测之人的亲缘关系等，这样才能做到准确无误。



预测自己的身体、出行的吉凶、比赛或打仗时我方的胜负，以世爻为用神。看世爻在卦中受日月生克的程度，以及与其它爻的生克关系如何，世爻受克少生多则吉，世爻受克多生少则凶。预测邻居、以及和自己不太相关的人、仇人、敌人、合作伙伴等时则以应爻为用神看。



此外其它情况，用神的取法则可以参考前面六亲所主含义定夺。



比如预测父母、爷爷、奶奶等长辈的吉凶时以父母为用神，预测车船，文书、契约时也以父母为用神；预测妻子，女友吉凶，则以妻财为用神，预测财运，买卖成败、保姆、雇员等也以妻财为用神；预测工作、升官、工作变动、升学、领导、丈夫吉凶等，则以官鬼为用神；预测生孩子、孩子的疾病、动物的吉凶等，则以子孙为用神，预测朋友、兄弟、姐妹、亲密之同事等的安危等，则以兄弟为用神。

# 第十章 元神、忌神、仇神



**一卦之中用神最为重要，用神的吉凶就是所测事物的吉凶，用神的吉凶取决于日月以及生克用神的爻对用神的作用。**

# 第十二章 五行生灭的 十二种状态



世界上所有的事物都包含有五行，都在五行的制约下从始到终变化着，象人一样具有生命，要经历生死。所以宇宙中存在着的所有事物都是无常的，没有永恒。正因为五行具有生死，所以宇宙的所有事物才会有生灭。



五行的生灭是按照一定的规律循环往复地不断运动着的，只要有阴阳存在，五行的作用就不会停止。五行从生到灭共有十二种状态，对应于十二地支。依次序为长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养。这十二种状态深刻地反映了事物从产生到发展、再到新生命开始的宇宙轮回规律，因为十二种状态是以长生为起点的，所以这一现象也被称之为长生十二宫。



五行生灭的十二种状态，古人认为只有长生、帝旺、墓、绝对事物的吉凶产生作用，其实这是对五行生灭十二种状态的错误理解。用神的吉凶，主要是从日月和卦中的动静生克来看的，而五行生灭的十二种状态，则是从象的角度反映了事物的变化状态而已，其真正的用途是在辨意。在六爻的高层次预测中，应用范围很广，必须熟练掌握。

# 第十三章 爻的动静与生克



六爻预测一切是围绕用神，看日月以及卦中的其它爻对用神的作用而进行判断的。在此说明一下动爻与静爻之间的力量以及生克关系。



老阴和老阳表示爻位有变化，称之为动爻，少阴和少阳表示爻位没有变化，称之为静爻。卦中出现动爻时，一般来说，**动爻可以生克静爻**，**而静爻则不可以生克动爻**，即使静爻旺相，动爻休囚也不可以。如果动爻休囚，不能作用于它爻时，等星移斗转，动爻变旺时就可以作用于静爻了，这就是为什么预测师可以从卦中判断出事情发生时间的原因。

# 第二十章 应期



所谓应期是指被预测事情吉凶发生的时间。应期分为两类，一种为过去应期，一种为未来应期。比如说预测婚姻，判断求测者以前的结婚时间，或者是谈恋爱时间，而预测疾病，判断病人得病的时间，就为过去应期。判断未来事情将要发生的时间，就为未来应期。



准确地判断出事情发生的时间，使求测人树立对预测的信心有很大帮助。这也是能够正确地把握就吉避凶的保证。



应期是预测中的一个难点，但大部分有规律可寻。应期的远近，要根据所测事情的不同灵活判断，远则以年、月判断，近则以日、时判断。

## 本领域用取与流程（分类专属，先于全局对应步骤执行）:

【用神惯例】占己病以世爻为用；占父母兄弟以对应六亲爻为用；占子女以子孙为用（六畜/宠物也以子孙）；占他人病以应爻为用；官鬼为病邪非必然病人，病人本人在世/应/六亲爻——两惯例并存时并列写出，以对象本人状态为终判。事件路径：重症→生死吉凶→病位取象→治期与死期。**【应期特例】病危/死期候选按序检索：①化神（退神/墓库）当值之日月、官鬼值月+实破（用神动化退/化墓或官鬼持世月破时优先：如退神丑·未当值之年、酉月官鬼值月+丑日入墓独发）②克用神之日月（仅无化退化墓结构的明确克神组合下居首）③用神墓绝/独发逢值④冲墓/出伏；病愈按近病逢空出空、元神出空值日、月破出月引用原文。**

【盲测纠偏·健康域（来自 857 例全领域盲测判定）】
1. **“化空/化退”不轻断病退**：子孙动化空而近病即愈，只在无三合局成形、无其他收凶结构时成立；若卦值三合（化神与日月/动爻成三合）则“化空”反成久病不愈之凶（如两卦俱值三合恐成久病而终、卒于次年末月）；用神动化退神可能是“精髓枯/药力退”的凶兆而非病退，须以原文断语为准，不能机械按“化空即愈”断。
2. **应期必须绑定使吉凶翻转的盘面触发**：病愈/病危应期不得列一串候选，须找到“使原神出空/冲墓/值日/破除”的那条触发并给出对应日月（如日辰冲开墓库当日午后愈、官鬼值月+丑日入墓独发主酉月、卒于冲墓之月/值太岁之月）；原注明示“卒于X月/愈于X日”的以原文为准。
3. **不硬推病因**：病位/病因取象只作佐证，最终以原文归因为准（剩饭所致/风寒入体/吵架伤胃/误诊寒热等）；不得把卦象硬推的风水/五行归因当作结论。
4. **近病/久病与生死分开**：六冲近病可愈不排除其久病/有变数的终局凶（须先断近况再按原注断终局），官鬼受制须核是“病邪退”还是“官方亡”且世应无伤。5. 吉凶截判先还原旺衰动变（同全局纪律），再定死期/愈期。
6. **隔山化爻须截断吉否**：动爻化出之爻又化出它爻（隔山化爻）时，须按完整化链断吉凶——如子孙化财、财又化官鬼（隔山化鬼）= 孕胎成局却终流产/子息有损之凶兆（原文"财爻未土动化官鬼酉金，此隔山化鬼，我说这个孩子生不下来"）；官鬼化父母又化兄弟（隔山化兄）= 手牌之伤、病灶向内部发展之凶兆（原文"官鬼爻隔父母化兄弟，等于官化兄，手脚之伤……病灶很麻烦不好治疗"）。不得因本级爻旺相就断吉，须把化链终局纳入。
10. 【健康/寿元通用规则】题面/原文带死亡结果（卒/亡/死于某时）一律截判，不得因子孙旺相/世旺断寿长；久病逢冲莫医（防凶）；病爻化退=病退可愈；妻占夫病子孙动克官=防子动伤夫，原文明言病情稳定以原文。

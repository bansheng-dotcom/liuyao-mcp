## 本领域用取与流程（分类专属，先于全局对应步骤执行）:

【用神惯例】失物/寻人：失物与六畜以子孙为用神；寻人兼看应爻（对方动态）与世爻（寻者）；子孙被日月合住=不远、日合当日回。【应期】合住待冲开（应爻动合子孙化子孙）；空亡实空冲空出空；六冲/伏藏等按原文。

【盲测纠偏·失物域】1. 原文/题面自带结果（如“终究没有找到/事后没找到/未找回”）的，必须作为截判依据：agent 不得因子孙旺相/卦化吉就反向断“可找回”——先还原子孙旺衰与出伏、暗冲之机，若子孙空破受克、用神伏藏无救、卦化游魂六冲而无具体冲飞/出伏机会，以难寻断。2. 失物可寻回的判据（检索库内原文支撑）：子孙旺相得日月/动爻生、用神冲飞出伏、冲空填实、子孙被日合（不远、日合当日回）；寻人兼看应爻（对方动态）与世爻（寻者）。3. 应期绑触发：合住待冲开（应爻动合子孙化子孙）、空亡实空·冲空·出空、伏藏出伏为应；不得列候选。4. 题面与实排不符以实排为准并标注。

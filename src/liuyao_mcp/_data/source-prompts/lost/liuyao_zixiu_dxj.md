# 第二十六章 预测行人



担心外出之人的安危，寻找失踪之人，预测在外吉凶和回家的应期，以六亲所主取用神。定好用神后，再看其在外情况，回家日期，和在外逗留的原因。用神宜旺，不宜休囚。同时也要看来预测人之念头如何，重点问回家日期的，用神不旺也无妨，重点问吉凶的，用神弱便为不好。

◎用神不宜动而化官鬼，非父母爻者，不病则凶。



◎世爻空亡，人回来的快。用神也空，就很难回来。



◎用神伏藏，喜飞神空亡，日月以及其他动爻冲克飞神。具体应期，参看应期章。



◎用神临日，静而合日，入日墓，为当日回家之象。



◎日辰动而化出用神，或用神动而化出日辰，当日回。

◎用神空而临呈蛇，行人在外处于不安的状态。



◎飞神为官鬼，临白虎，人在外不顺。不是生病遇灾，就是被人殴打。



◎飞神为兄弟临玄武，或在外失物，或在外贪恋女色，或在外赌博，不会马上回来。



◎用神伏子孙下，乐不思蜀，或沉溺于酒，或被晚辈挽留，不能马上回来。



◎用神伏在父母下，或在年长人之处，或在旅馆，或因文书、手续之事而留。



◎用神伏在妻财下，或因钱财之事，或因女人，或在女人家中，不能马上回家。



◎用神空而遇死绝之地，休囚被克者，在外凶多吉少。

◎卦中妻财不现，或临空亡，在外缺钱花。若被兄弟发动克伤，必在外钱被人偷。



◎被测人为女子，不宜用神与官鬼相合，不是被人拐骗，就是多灾多难。



◎父母为消息，在卦中发动，乃是有消息或书信、电话的信息。临朱雀动更验。



◎父母休囚被克，又临空破，为没有一点消息的卦象。



◎卦中有反吟伏吟，人在外奔波，不安。



◎归魂有归心，游魂无归心。

◎预测行人的方位和场所，以用神为中心判断。用神安静，以用神所临地支判断，用神发动，以变爻、变卦定方位，用神伏藏，以飞神所在之卦判断或以飞神所临地支判断。用神入墓或被合时，又以合神以及墓库地支判断方位。



◎以墓库定地方，辰土为西南或水边、水库等地方，戌土为砖厂、寺院等地方，未为木材加工厂、花园、林中等，丑为工厂、金属仓库等。此只是一个思路，具体可以根据卦的情况灵活判断。 



- 兑为寺院、沼泽、少女之所，乾为大城市、庙宇，震为闹市、森林，巽为树林、妇女处，坤为人多处，原野、老妇处，艮为山林、坟墓处等。　



◎用神在世爻或内卦，在近处，在外卦，六爻为远处。

# 第二十七章 预测失物



小偷进家，或者是丢失了东西，如果是不太重要的东西，当然一般人不会在意。但是如果是比较贵重的东西或者是有纪念意义的东西，就会十分着急，请求预测。其实不管是重要的东西，还是不重要的东西，对于学习六爻预测的人来说，都应该预测一下，这对于提高预测水平大有帮助。



预测失物，根据失物的性质不同，用神也不一样。如果是书籍、信件、证书、车、衣服等就以父母爻为用神，如果是日用品、钱、贵重东西就以妻财为用神。



◎子孙持世，是自己不小心把东西忘在什么地方了。



◎子孙发动，妻财旺，失物可回。



◎世爻临呈蛇，多为自己忘记了放东西的地方。游魂卦也为忘记了东西，归魂卦失物在家，或离家不远。



◎妻财在内卦，化入空亡，乃是家里人拿了或是内部人所为。



◎用神伏藏，被日冲，东西没有被盗，是有人移动了地方。如果官鬼安静，失物可回。



◎用神旺相生世，克世，失物可回。



◎用伏藏，飞神空亡，失物可回。飞神逢冲，失物也可回。



◎预测失物的所在场所，以用神地支和卦宫判断。伏藏时，以飞神的六亲或飞神所在的卦判断。



◎妻财发动化官鬼，要找的东西被盗。官鬼发动化妻财，失物还在附近，容易找见。



◎用神临木，到草丛中，到木器旁找，临水到水边找，临土在土堆附近，临金在金属器旁，临火在窑灶旁，或火炉旁等，此皆泛指，具体要灵活判断。



◎卦中显示东西丢失，官鬼持世，或临月建，为熟悉的人、自己人、邻居所偷。



◎官鬼在二爻发动，是入室盗窃，临玄武为惯偷。



◎官鬼两现，非一个人作案。内外官鬼，里应外合。官鬼逢冲，有人撞见。



◎官鬼空亡，用临应爻，是自己把东西借给人了，或是忘在了别人家里。



◎盗贼的性别看官鬼爻的阴阳，阴为女，阳为男。又以官鬼对应于五行生灭十二状态看偷东西人的年龄。临官、帝旺者，年轻人，墓、衰、绝者，老年人，胎、养者，小孩。此也非死法，需要活看。带刑者，入过牢狱之人，临白虎者，身上带有武器，或有病之人。



◎以六神，五行等判断偷东西人的相貌。



◎用神为父母爻的，同时也要结合妻财的衰旺，判断失物可否找回。



◎用神在外卦，失物在外丢失，或东西被偷到了远处。



◎用神安静易找，发动，难找。用神宜旺，不宜空破。世克用神，失物难找回。用神克世，易找回。



◎用神伏或入墓，东西不在明处，逢合，多在器物内，地下室、仓库等。用神入墓于父母，或伏在父母下，多在衣服，车内，家中寻找。判断时，可以结合爻位进行判断。



◎如果东西被偷，子孙持世，盗贼易捕得。子孙在卦中发动，也容易找偷东西的人。因为子孙为警察。



◎官鬼安静易捕，发动或伏藏难捉。官鬼生合世，盗贼投案自首，克世，狗急跳墙恐伤人。



◎官鬼化进，盗贼已经走远，化退，还会回来，合妻财，二次进入现场作案。



◎官鬼动而生合应爻，盗贼逃往他乡。官鬼旺则难捕，被克则易捉。



◎寻找线索或目击证人，以动爻判断。

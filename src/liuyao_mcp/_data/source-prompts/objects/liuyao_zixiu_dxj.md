# 第九章 取用神的方法



六爻预测最重要的、最先进行的是取用神。**用神是展开六爻预测的核心，一切事情的吉凶与发展都围绕着用神来分析推理，用神取错，失之毫厘，差之千里。**因此，在预测时，必须问明求测者的目的或来测者与被测之人的亲缘关系等，这样才能做到准确无误。



预测自己的身体、出行的吉凶、比赛或打仗时我方的胜负，以世爻为用神。看世爻在卦中受日月生克的程度，以及与其它爻的生克关系如何，世爻受克少生多则吉，世爻受克多生少则凶。预测邻居、以及和自己不太相关的人、仇人、敌人、合作伙伴等时则以应爻为用神看。

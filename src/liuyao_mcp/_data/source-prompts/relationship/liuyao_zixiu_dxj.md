# 姻缘感情 · 六爻预测自修宝典（DXJ整理版）

以下为原书正文。原注、新评及原例按原顺序保留；原例反馈不属于当前问题。

预测婚姻，用神与世应的关系非常重要。女人预测婚姻，以官鬼为用神，以应爻为夫位，男人预测婚姻，以妻财为用神，以应爻为妻位。或以世爻为预测人的家庭，应爻为婚姻对方的家庭。



◎预测婚姻，宜用神旺相，生合世爻，不宜休囚空破，或克世、生合应爻。



◎世应相生合则吉，易成夫妻，相克则不吉，易两人分离。



◎世应五行相同，多借媒人之力成就婚姻。世应相克，若有动爻通关，以解二者之克，乃是通过别人的帮助，婚姻获得成功。

◎男的预测婚姻，世生应爻，或用神，是男的喜欢女的，发动，乃是男的主动追求对方。应或用神生世爻，乃是女的愿意交往。



◎间爻动而生忌神，或间爻为忌神发动时，有人从中挑拨二人关系。



◎世爻旺而克应，多为嫌对方家庭地位低，家底薄，家庭不富裕。



◎世应纳支同在一卦，两人为同学、同事、或老乡等关系。



◎二人是否真心相爱，看世应如何，相生相合，用神旺而持世，二人同心，世应有一空亡，就不会一心一意。世应都空，彼此欺瞒，各怀鬼胎。



◎妻财临白虎克世，女人厉害，受妻子欺压，或妻子不孝敬公婆。



◎世爻入墓于妻财或应爻，为怕老婆。世爻动而生应上妻财，为入赘女家。妻财临二爻尤其应验。

◎未婚，用神动而化进，对方非常想成就此婚姻，化退，将来会变心，远离而去。



◎用神不宜与旁爻相合，出现相合多为婚外情。



◎世应也不宜动而化退，化退，一方有退悔之心。



◎男测婚，不宜兄弟持世，女则不宜子孙持世。男测婚，不宜应爻化财，女测婚，不宜应爻化官。



◎卦中有用神，不宜再动而化出与用神五行相同的六亲。多为婚外情。



◎预测婚姻，不宜财官互伏，也不宜伏在兄弟爻下，表明对方有第三者，或为有家室之人。



◎六冲，夫妻感情不和，六合，婚姻相对稳定。

# 全局断卦流程与原文

先按以下顺序建立主线。步骤标题和“本步执行”只说明阅读与核查顺序，不新增断法，也不替代任何作者原句。每步后的正文均按当前数据库的来源范围保留；同一段文字出现在不同步骤，是因为它同时约束多个判断环节。细则、例外和案例仍由数据库按实际盘面补查。

## 第1步：先定原问、来意、对象与时限

本步执行：先锁定本题要回答的核心事项、人物关系、动作方向和期限；不以泛泛的事项名称替代实际来意，也不先把细节象义当作主答。

# 第九章 取用神的方法



六爻预测最重要的、最先进行的是取用神。**用神是展开六爻预测的核心，一切事情的吉凶与发展都围绕着用神来分析推理，用神取错，失之毫厘，差之千里。**因此，在预测时，必须问明求测者的目的或来测者与被测之人的亲缘关系等，这样才能做到准确无误。



预测自己的身体、出行的吉凶、比赛或打仗时我方的胜负，以世爻为用神。看世爻在卦中受日月生克的程度，以及与其它爻的生克关系如何，世爻受克少生多则吉，世爻受克多生少则凶。预测邻居、以及和自己不太相关的人、仇人、敌人、合作伙伴等时则以应爻为用神看。

二，围绕卦主所求之事的核心推理取象。不少初学者羡慕于象法的神奇，在初学阶段理论根基尚不稳定的情况下抛弃理法，专攻象法，只采其花，不顾茎叶。如在各大群内所常见的卦主问投资，问婚姻，易友一通取象猛如虎，全家上下断了个遍，就是不断投资婚姻情况，追问之下，答：不会看。如此岂不哗众取宠，本末倒置？不能解决卦主疑惑，不能为卦主趋吉避凶、指点迷津、提出建议，何谈解卦？所以一个卦，除了前期必要的验证对应以外，应该以卦主所测的事情为核心，围绕这个核心去综合分析事情的前因后果，而不是眉毛胡子一把抓。解决了核心问题之后，其他的信息可以作为辅助信息进行解答，这样可以条理清楚，思维清晰而不至于混乱，卦主也满意。

## 第2步：再核时间与盘面事实，确认动变边界

本步执行：核对年月日、六神、世应、六亲、动爻及本位变爻；盘面事实与后续断法分开。动爻有变时，先确认变爻只作用于本位动爻的边界。

凡学占者，须要先念“浑天甲子、六亲歌”，占出卦来，会装五行六亲，再学动变。卦中既有动爻，动则必变。即知动变，然后再看用神、元神、忌神，知此者，即如入周易之门也。



　再看四时旺相章、五行相生相克章、五行相冲相合章、旬空月破生旺墓绝章，又如生周易之堂矣。再看后卷各门各类，占何事，以何法断之，渐渐由浅入深，自臻其奥，不须半载工夫，得余数十年之秘学也。今余先点一卦，教尔学看用神及五行生克旺衰之理于后。



凡问事者，先写年月日辰，再照六神章中写出六神，然后占卦。

本步执行：依原问、来意和亲缘确定主用神；同时保留世、应、元神、忌神等与主用神有关的角色。把人物当前状态、事件最终结果、求测人得失或喜忧、应期分开成需要回答的维度；取用有分歧时不得偷换成单一结论。：同一动爻或同一结构同时具备吉凶两种直接语义时（如子孙发动化出财爻=可回 vs 子孙被日辰合=贪合忘生、化出之爻又空亡=吉象不成立；官鬼旺相=对方强势难拘 vs 子孙旺相制鬼=可擒），必须把两条直接规则并列写出并按原文处理次序（合绊优先、化空/出空、旺衰权衡、先到先应）取舍得失，不得只取吉线；被舍一方保留在uncertainties。 且须先检索库内冲突处理次序原文（如「月破得日建合/填实」「贪合忘生」「化空不吉」等）并引用之，再作取舍。先读对应领域提示词的分类取用惯例并确认书用（方向矛盾以对象本人/本物状态为终判）。。【来意反推（凭盘面主动判，代替分支罗列）】题面无明确来意（无问题/仅盘面）时不是“不得臆测”，而是要凭盘面主动反推最可能事类并直接下判：①六亲持世（官鬼=求官/官非/忧，子孙=解忧/子女/医药，父母=文书/考试/长辈，妻财=求财/姻缘，兄弟=破耗/争夺）；②动爻化进/得生=成象，化退/冲克=败；③世应：应生世=得助，应世世=受制，六合=和易成，六冲=散；④按最强前兆给出单一主判+置信度（高/中/低）+盘面论据，其他可能来意一行带过，绝不只列分支更不以“来意未知”戛止。题面含“第X章举例/选自实占”时按题面原题主题判。（other 域盲测 210 例一致率 35% 的主要失分点：无来意/分支题 agent 乱定向）。。**【题面自带结果的强制应用】**凡题面/题包出现“选自实占卦例/第X章举例N/反馈/结果/原著”且含明确作者结论（如“主队胜”“已通过81分”“卯月巳月升迁”“果考于三月”“病化退会好”“可以找回来”）时，该结论即判据：agent primary 必须与之对齐，方向相反必须自我纠正并说明；不得因“来意未标/举例/无来意”跳过结论只按盘面泛列。【比赛胜负主客】占比赛/较胜者须先定世应各代表谁（我方=世、对方=应或题注说明），再判胜负方向，不得因来意未标只列分支。.**【无来意题主判要求】**题面仅存盘面/“第X章举例N”等而无明确来意时，除列分支外**必须给出主判与置信度**（最可能来意下的结论），不得以“来意未知/待问明”敷衍；盘面有强势指向（子孙持世=解忧、官鬼持世=求官官非、世应冲=事散）按最强指向给主判。**【教学/理论题断结论】**教学/理法/举例题须在陈述规则后给出该例授业结论（此例教什么+若实占会断什么），不得只讲规则不落地。**【用神成败裁决·通用】以用神为本：用神旺相（得日月生/持世/化进/合局/暗动生/世化用神）即主成；单一爻受克/旬空/月破而用神仍有救者不翻败；仅当用神休囚无救或被克死才断败；世应细节只改应期不改方向。比赛类:以世应实际旺衰+暗动+原文特则定胜负，不得机械“应旺我弱即输”。【原文显式结果优先于旺衰推演】凡题面/原文已明示最终结果时，**该结论覆盖一切旺衰/合局推演**：不得因官鬼父母旺相/合局/化进而把文明显示的“没过/没录”翻成“能过/能录”，也不得把“果升/果录”翻成“不成”。官父旺衰仅用于无显式结果的推演；有显式结论一律截判。。【裁决顺序铁律】凡以官鬼/父母/妻财为用神的吉凶裁决按此顺序执行（考试/求职/官事细节见领域提示词），不得跳步：①先查题面/原文显式结果（差一分没上/果升/果未录/结果没通过）→有则直接截判无条件覆盖；②官鬼（或父母）为用先判旺衰：旺相=得日月生/持世/三合官局成/化进/暗动生/世化用神任其一即算有救，有救即主成——单一爻受冲克/旬空/月破，只要官仍有日月生扶或合局救应，不得翻判为败（旺相之空待出空填实仍主成）；③仅当官鬼休囚且无任何救应、或用神真被克死（合化皆无）才断败；④世应细节（世破/财空/文书迟）只影响应期与过程，不改吉凶方向。比赛题：先定世应代表，叠加暗动与原文准则，不因一方应旺直接判胜。

# 第十三章 爻的动静与生克



六爻预测一切是围绕用神，看日月以及卦中的其它爻对用神的作用而进行判断的。在此说明一下动爻与静爻之间的力量以及生克关系。



老阴和老阳表示爻位有变化，称之为动爻，少阴和少阳表示爻位没有变化，称之为静爻。卦中出现动爻时，一般来说，**动爻可以生克静爻**，**而静爻则不可以生克动爻**，即使静爻旺相，动爻休囚也不可以。如果动爻休囚，不能作用于它爻时，等星移斗转，动爻变旺时就可以作用于静爻了，这就是为什么预测师可以从卦中判断出事情发生时间的原因。

# 第二十章 应期



所谓应期是指被预测事情吉凶发生的时间。应期分为两类，一种为过去应期，一种为未来应期。比如说预测婚姻，判断求测者以前的结婚时间，或者是谈恋爱时间，而预测疾病，判断病人得病的时间，就为过去应期。判断未来事情将要发生的时间，就为未来应期。



准确地判断出事情发生的时间，使求测人树立对预测的信心有很大帮助。这也是能够正确地把握就吉避凶的保证。



应期是预测中的一个难点，但大部分有规律可寻。应期的远近，要根据所测事情的不同灵活判断，远则以年、月判断，近则以日、时判断。
